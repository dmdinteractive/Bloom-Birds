      Axis Layout
      #NameXYMechanismSizeMax speedMax accelTrimTravel

      X/Y are plan-view positions (0–1) used by wave, ripple and spin patterns. Mechanism and Size are set in Motor Setup (Size = spool diameter mm, screw lead mm, or gear ratio). Max speed/accel are in each motor's units per second (mm, °, rev); blank uses the defaults. Trim offsets one axis; Travel applies until the ends are taught.

      Motor Groups

      Groups (e.g. left wing / right wing, flock A / flock B) can be the target of a clip or of a layer in a layered clip, so different parts of the sculpture can do different things at the same time.

      OSC

      From TouchOSC, QLab, Max, a show controller… Messages like /bloom/flap 1.

      MIDI
      —

      Plug a USB MIDI controller into the Pi. Every connected device is read; notes, CCs and program changes.

      Art-Net / DMX

      From a lighting console on the network (UDP 6454). Universe is the 15-bit Art-Net port-address (0 = first). Channels 1–512.

      Pi GPIO

      Pin numbers are GPIO (BCM) numbers, not header positions. A button goes between the pin and GND. Sensors (PIR, beam break) must output 3.3 V, never 5 V.

      Mappings

      Learn waits for the next input that arrives and fills it in: press it, then hit the button, move the fader or send the message. Fire actions happen when the value rises past half (once per press); speed and intensity follow the value continuously. A note without a channel (note 60) matches any channel. Operator buttons (Run, Hold, Next…) always override a triggered clip.
